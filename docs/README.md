## Модули и функции
### circle
1) **area**  
    Возвращает площадь круга с радиусом r.  
    Принимает на вход целое число (радиус, r).  
    Возвращает вещественное число - площадь круга, полученную в результате вычисления по формуле:
   
    $$πr^2$$
3) **perimeter**  
    Возвращает периметр окружности с радиусом r.  
    Принимает на вход целое число (радиус, r).  
    Возвращает вещественное число, результат вычисления по формуле:
   
    $$2πr$$
   
### rectangle
1) **area**  
    Возвращает площадь прямоугольника со сторонами a, b.  
    Принимает на входе два целых числа: a, b - длины сторон прямоугольника.  
    Возвращает целое число, результат вычисления:
   
    $$a\cdot b$$
   
3) **perimeter**  
    Возвращает периметр прямоугольника со сторонами a, b.  
    Принимает на входе два целых числа: a, b - длины сторон прямоугольника.  
    Возвращает целое число, результат вычисления:
   
    $$(a+b)\cdot2$$
   
### triangle
1) **area**  
    Возвращает площадь треугольника c основанием a и высотой h.  
    Принимает на входе два целых числа: a - длина основания треугольника, сторона к которой проведена высота, h - длина высоты треугольника, проведенной к основанию a.  
    Возвращает вещественное число, результат вычисления:
   
    $$\frac{a\cdot h}{2}$$
3) **perimeter**  
    Возвращает периметр треугольника со сторонами a, b, c.  
    Принимает на входе три целых числа: a, b, c - длины трех сторон треугольника.  
    Возвращает целое число, сумму длин сторон:
   
    $$a + b + c$$
### square
1) **area**  
    Возвращает площадь квадрата со стороной a.  
    Принимает на входе целое число (a, длина стороны квадрата).  
    Возвращает целое число, результат вычисления:
   
    $$a\cdot a$$
3) **perimeter**  
    Возвращает периметр квадрата со стороной a.  
    Принимает на входе целое число (a, длина стороны квадрата).  
    Возвращает целое число, результат вычисления:
   
    $$4a$$
### maths
1) **square**  
    Возвращает квадрат числа n.  
    Принимает на входе вещественное число n.
    Возвращает вещественное число, возведенное во вторую степень:
   
    $$n^2$$
3) **add_binary**  
    Возвращает сумму двух десятичных чисел в двоичном формате.  
    Принимает на вход два десятичных целых числа a, b.
    Возвращает строку, сумму чисел a и b в двоичном формате.
    Перевод суммы в двоичный формат реализован записью:
    `f'{(a+b):b}'`
4) **get_root**  
    Возвращает b-корень из числа a:
   
    $$\sqrt[b]{a}$$
   
    Принимает на вход:  
    a - целое неотрицательное число, подкоренное число.  
    b - целое число, показатель корня. Не равен 0.  
    Возвращает вещественное число, результат вычисления формулы:
   
    $$a^{\frac{1}{b}}$$
   
    Такая запись позволяет избавиться от необходимости импортировать сторонние библиотеки.
6) **is_prime**  
    Возвращает True если число n простое, иначе False.  
    Принимает на вход целое число n.  
    Возвращает True или False (bool).  

    Принцип определения простоты числа:
    Если  $n\leq1$, то возвращает False, так как отрицательные числа, 0 и 1 не являются простыми числами.  

    Далее алгоритм перебирает делители (i) от $2$ до $\sqrt{n}$ включительно. Если хотя бы один из делителей делит n без остатка, функция возвращает False, так как это значит, что число составное. Если ни один из делителей не делит n без остатка, функция возвращает True, так как число простое (делится только на 1 и на себя).
